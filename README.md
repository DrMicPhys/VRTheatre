
Virtual Theatre Space (OER)

An Open Educational Resource (OER) designed to provide students and performers with an accessible, immersive environment for theatrical rehearsal and performance practice.

Project Highlights

• Virtual Theatre Space: Explore and rehearse inside realistic digital stage environments.
• Script Teleprompter HUD: Read and practice lines naturally using an integrated heads-up display for script segments.
• Safe Practice Space: Build confidence, experiment with blocking, and rehearse scenes in a low-stakes, self-paced setting.
• Classic and Modern Theatres: Experience different spatial dynamics across both historic and contemporary venue designs.
